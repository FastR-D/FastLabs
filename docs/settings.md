# 设置中心

## 页面结构

设置中心是 FastLab 单页应用中的独立视图，不是新的 HTML 页面，也不会打开新的浏览器标签页。
用户从首页或任务详情点击“设置”后，主内容区切换到设置视图；左上方显示“← 返回”，用于回到
进入设置前的页面和任务。

桌面端采用两栏结构：左侧是设置分类，右侧只显示当前分类的内容。分类顺序固定为：

1. **Agent 配置**：Planner、Worker、Verifier 的 Agent、模型和推理等级，以及执行器可用状态。
2. **模型凭证**：Codex CLI、Claude CLI 或个人 API Key 的选择与状态说明。
3. **Skill 配置**：当前用户自己的任务分发 `orchestration` Skill，可保存或恢复内置模板。
4. **仓库管理**：创建空仓库或从 HTTPS Git URL 克隆到当前用户大工作目录；不填写服务器路径。

右侧不能同时堆叠多个分类表单。窄屏下左侧分类栏变为可横向滚动的页签，仍然一次只显示一个
分类。分类名称和顺序属于用户界面契约；新增分类应同步更新本文件、前端测试和 `plan.md`。

Agent 配置中的模型使用严格下拉框。第一项是“CLI 默认模型”，其余选项来自服务器针对当前
Codex/Claude Agent 返回的允许列表；切换 Agent 会立即替换模型选项，不允许自由输入任意名称。
已保存但后来被移出允许列表的模型以“历史配置”保留显示，便于查看旧配置和任务。

## 导航与表单状态

- 首次进入默认打开“Agent 配置”。同一次前端会话再次进入时可以保留上次选中的分类。
- 创建任务页没有可用仓库时，“添加仓库”直接打开“仓库管理”；点击“← 返回”回到创建任务页。
- “← 返回”恢复进入设置前的首页或任务详情，而不是一律跳回首页。
- 切换分类或返回前若当前表单有未保存改动，必须先请求用户确认；取消后停留在原分类。
- 保存成功后留在当前分类并刷新该分类的数据，不改变用户的返回目标。
- 设置中心沿用应用内渲染和事件委托，不新增后端页面路由；浏览器刷新仍由 `/lab/` 入口恢复应用。

## 数据和安全边界

设置中心只是已有用户设置 API 的分类入口。Agent、凭证、Skill 和仓库仍分别使用原有接口，
保留模型白名单、密钥掩码、租户目录、Skill 大小与路径校验。导航状态只存在前端内存，不写入
任务快照；保存后的实际设置继续按现有规则写入当前租户，并在创建任务时固化。

未填写 API Key 时默认使用用户空间中的 Codex CLI 登录。CLI 登录态、个人 API Key、Skill
和仓库均不得跨用户共享。

## 仓库管理

生产 `research` 模式只要求仓库名称和可选 Git URL。名称用于页面和任务选择，实际目录由 FastLab
生成在当前租户的 `repositories/<repository-id>/`。Git URL 为空时创建带初始提交的空仓库；
填写时只接受不含凭证的 `https://` URL。页面不展示宿主绝对路径，也不允许用户猜测相对目录。

普通本地开发模式使用相同的托管页面和 `<data-dir>/repositories/`。只有显式传入旧
`--workspace` 参数时才进入路径兼容模式，用于避免既有开发脚本失效；多用户服务器和默认本机
页面都不显示路径输入。添加仓库表单位于已有仓库列表上方，进入仓库管理后无需滚动到底部。

托管仓库只提供“永久删除仓库”，不提供会留下孤立磁盘目录的“仅移除记录”。永久删除会清除
登记以及 FastLab 生成的仓库目录、所有文件、提交和未推送内容，必须二次确认；有未结束任务时
不可用。显式 `--workspace` 的外部目录不归 FastLab 管理，只允许移除记录，网页永远不能删除其文件。
