# 常见问题

## `HEAD` 未知或有歧义

错误类似：

```text
fatal: ambiguous argument 'HEAD': unknown revision or path
```

目标目录还没有初始提交。进入网页“设置”，在仓库旁点击“创建初始提交”；非 Git 文件夹首次登记时，也可以确认让 FastLab 一键初始化。执行前检查 `.gitignore`，避免提交敏感文件。

## 目标仓库存在未提交改动

FastLab 要求开始任务和最终交付时目标目录保持干净，避免覆盖用户修改。正常修改可以先提交，再点击“应用结果”：FastLab 会在隔离的集成 Worktree 中同步该提交并重新验收，通过后再交付。也可以把改动暂存到其他位置或手工撤销。

如果新提交与任务结果冲突，或目标分支历史被改写，FastLab 会保持目标目录不变并明确报错；此时应处理冲突，或使用“继续修改”从当前目标代码创建新任务。

## Codex 或 Claude 不可用

在终端分别检查：

```bash
codex --version
claude --version
```

确认 CLI 已安装、已登录，并且 `.fastlab/fastlab.env` 中的 `FASTLAB_CODEX_BIN`、`FASTLAB_CLAUDE_BIN` 指向正确命令。某个 CLI 不存在只会让对应 Planner 或执行器显示不可用，不应阻止 FastLab 网站启动。

## Claude 命令被拦截

不要启用危险权限绕过。根据日志中的具体命令配置精确规则，参见[Claude 执行权限](claude-permissions.md)。

## Claude 退出代码 1

任务错误会保留 Claude CLI 最后一条真实原因，而不只显示退出代码。常见原因包括余额不足、登录失效、模型不可用、命令权限、系统沙箱、网络和项目依赖问题。先处理具体错误，再对失败子任务点击“重试”；如果会话和 Worktree 仍在，也可以“追加说明”。如果所有子任务已经成功、只有最终验收失败，可以在“重新验收设置”中更换 Codex/Claude，再点击“重新验收”，无需重新执行子任务。

## 原 Agent 现场已清理

“追加说明”只能复用同时保留 Worktree 和会话 ID 的原子任务。如果任务已成功交付或手工清理临时数据，请点击“继续修改”，FastLab 会从已交付代码创建并规划一个新任务。“重新运行”不会使用新的追加要求，只会再次执行原始目标。

如果子任务已经成功、任务处于暂停状态且 Worktree 尚在，可以展开该子任务，在“带新要求重跑”中同时填写新增要求、选择新执行器和模型，再点击确认按钮。这会启动新会话；如果想保留原会话上下文和原模型，则展开“继续原会话”，确认发送目标后填写追加说明。

## Agent 运行超时

Planner、Worker 或 Verifier 超过 `FASTLAB_AGENT_TIMEOUT` 后，FastLab 会终止整个进程组并记录超时错误。默认值为 3600 秒，设为 0 表示不限制。超时和用户主动停止是两个独立原因；处理现场后可以按状态选择“重试”“追加说明”或“继续修改”。

## 合并冲突

FastLab 会中止本次合并，把任务标记为需要处理，并保留子任务分支和 Worktree。目标分支不会被修改。可以检查冲突原因后重新运行任务，或手工处理保留的分支。

## 验收通过但没有出现在目标目录

通常是安全交付检查失败，例如目标目录变脏、切换了分支或新提交发生冲突。提交正常修改后可点击“应用结果”，FastLab 会自动同步并重新验收。不要直接复制 Worktree 文件覆盖目标目录。

## 验收显示 `unclear`

这表示验收 Agent 没有发现明确代码失败，但当前环境不足以证明某项标准。Codex 验收会在临时 Worktree 中运行，并仅开放 localhost，因此可以启动本地服务、执行 HTTP 或无头测试，同时不会修改实际集成分支或访问公网。相关安全边界参考 [OpenAI 官方 Agent approvals & security](https://learn.chatgpt.com/codex/agent-approvals-security)。

如果项目没有可用的浏览器自动化测试，真实点击、视觉效果或设备适配仍可能需要人工检查。展开“验收结果”，按每个 `unclear` 项给出的步骤在目标目录验证；确认无误后点击“人工确认并应用”并填写实际证据。该入口只能确认 `unclear`，不能覆盖任何 `failed`。

长期做法是在实现子任务中补充无需公网的单元测试、DOM 测试或无头浏览器测试，让以后验收可以自动复现，而不是单纯更换模型。

## 停止或失败后分支越来越多

停止和失败默认保留现场以支持重试。确认不再需要后，点击任务页的“清理临时数据”；删除任务也会删除该任务的 Worktree 和任务分支。成功交付的任务会自动清理。

## 网页内容定时更新影响操作

网页会轮询状态，但编辑表单时不会重绘主要内容；任务详情会保存展开状态、页面位置以及日志和文档的内部滚动位置。如果仍出现跳动，请保留浏览器控制台错误和具体操作步骤。

## 飞书机器人不回复

检查应用是否发布、长连接是否启用、事件和权限是否生效、用户 Open ID 是否属于当前应用，以及群聊是否 @ 机器人。完整步骤见[飞书机器人配置指南](feishu-bot.md)。
