# ADR-0004：统一托管仓库与 process 执行方式

- 状态：已接受
- 日期：2026-09-28
- 取代：ADR-0001 的根目录导入门面；ADR-0002 的可选 Docker 后端

## 决策

本机与多用户模式统一使用 FastLab 托管仓库。移除 `--workspace`、外部路径登记及仅移除记录接口；永久删除继续要求目录归属检查、活动任务保护及页面确认。

删除 `agent_adapter.py`、`multitenancy.py`；`server.py` 仅启动服务，调用者统一从 `fastlab.*` 导入。删除外部路径初始化确认错误，托管仓库仍可修复初始提交。

仅保留 process 执行方式，删除 Docker Runner、镜像构建文件、容器配置和后端选择配置。旧配置明确拒绝启动，不能静默回退。

## 后果

旧脚本和配置需按 [API 变更](../api.md#本次清理的接口变更)与[配置参考](../configuration.md#已移除配置)迁移。数据库结构迁移继续保留，清理本机开发数据不代表自动删除其他部署的数据。

生产仍只面向可信内部用户，必须通过 Linux 沙箱门禁。更强隔离需要另行设计、实现并验证，当前不存在可切换的容器后端。模块化单体、ExecutionRunner 契约及单实例部署边界保持不变。
