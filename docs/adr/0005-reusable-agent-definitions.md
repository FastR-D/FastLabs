# ADR-0005：可复用能力定义与任务级执行实例

- 状态：已接受
- 日期：2026-09-28

## 决策

增加租户独立的版本化 Agent 库，用户管理定义，任务保存配置快照。
Planner 选择已有定义或输出任务内临时定义，用户确认后由 FastLab 统一调度。
任务继续承载目标、依赖、验收和交付；CLI 会话与单次调用记录独立于定义版本。

沿用 Codex、Claude 和 process Runner、Worktree、现有并发门与 Dispatch 保护。
不引入 Agent 继承、常驻进程、跨任务自动记忆或 CLI 内部递归派发；agent-git 暂缓。

## 理由与后果

能力定义便于长期复用；任务快照阻止修改定义影响历史工作。
统一调度保留取消、并发和日志的可见性；复杂动态协作留待后续单独设计。
增量数据库迁移需一致性备份；归档保留历史版本，旧执行器接口继续作为兼容输入。
